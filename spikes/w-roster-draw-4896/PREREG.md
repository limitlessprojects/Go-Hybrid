## 0. 实验对象与口径

策略 A（issue 原文的 8 班次问题）：

- 可见字母表 `ABC`；horizon `n = 8`。
- 相邻不得同人。
- C 最多 2 班（`C ≤ 2`）。
- 必须指定恰好一处 `A→B` 交接作为培训位；haroff 位置是**私有选择**，不进入公开 roster。
- 公开产物 = 8 长字符串（roster）；私有产物 = 交接边界下标。

「合法 (roster, handoff) 对」定义：roster 满足前三条且至少含一个 `A→B` 边界，handoff 是其中任意一个边界。
因此 `multiplicity(roster) = #{i : roster[i]=A, roster[i+1]=B}`。

策略 B（长 horizon 对照）：字母表 `ABCD`，相邻不得同人，`C ≤ 3`、`D ≤ 2`，至少一处 `A→B`，`n = 12`。
策略 C（规模曲线族）：字母表 `ABCD`，相邻不得同人，`C ≤ 2`、`D ≤ 1`，至少一处 `A→B`，
`n ∈ {8, 12, 16, 20, 24, 32}` 只跑计数与计时（不抽样）。

## 1. 假设与证伪条件

### H1（独立枚举复现 issue 的关键数字）

用一个**与提案机制无关**的穷举器（直接生成 8 长具体词 → 用词面判据检查约束 → 逐个枚举 `A→B` 边界），
应当得到：

- 可见 roster 数 `|W| = 151`
- 合法 (roster, handoff) 对数 `|P| = 284`
- multiplicity 直方图 `{1: 43, 2: 84, 3: 23, 4: 1}`

**证伪条件**：任一数字不等于上值。

证伪时的处置：以我的枚举为准，报告差异，并给出差异的最可能来源（约束歧义 / 边界语义），
**不允许**为了对上 issue 而改判据。

### H2（三个实现的抽样偏差）

- **H2a 错误实现 1（对 (roster,handoff) 对均匀抽）**
  roster 频率 ∝ multiplicity。χ²(150) 对「均匀」原假设的 p < 1e-6；
  `ABABABAB` 与 `ABACACBA` 的频率比 4:1，95% CI 覆盖 4。
  证伪：p ≥ 1e-6 或比值 CI 不含 4。

- **H2b 错误实现 2（先均匀抽 roster，再在合法 handoff 中均匀挑一个）**
  roster 边际是均匀的（χ²(150) p > 0.01，即**通不过这条就说明实现写错了**）；
  但 reveal（handoff）不是 roster 的函数：条件熵 `H(handoff | roster) ≈ 0.8109 bit ≠ 0`，
  同一 roster 两次独立抽取的 reveal 一致率 `≈ 0.6153 ≠ 1`。
  证伪：一致率落在 [0.99, 1] 内（说明 reveal 其实由 roster 决定），或条件熵 < 0.1 bit。

- **H2c 正确实现（确定化 + 大整数计数 + rank 分块）**
  每个 roster 频率 = 1/151；χ²(150) p > 0.01；`max |p̂ − 1/151|` 在 99.9% 抽样误差内；
  `ABABABAB : ABACACBA ≈ 1 : 1`；rank 0..150 解码出 151 个互异 roster，且与独立枚举的字典序列表逐项相同。
  证伪：χ² p ≤ 0.01，或 rank 解码出现重复/缺项/与 oracle 不等。

统计口径统一：每配置 100,000 次抽样；151 个 bin；α = 0.01（H2a 单独用 1e-6，因为它是「应当被拒绝」的方向）。

### H3（契约：增加第二个私有理由不得改变概率）

构造一个**行为等价的重构** `PolicySplit`：把「指定交接」这条私有分支在 `C 已用 = 0` 时写两遍
（两次产生**同一个**私有状态元组）。可见语言、可见计数应当不变，私有路径数翻倍。

- **H3a 确定化实现满足契约**：`|W|` 仍为 151；rank 0..150 解码的 roster 与重构前**逐项相同**；
  目标 roster（`ABABACAC`、`ABACABAB`）频率仍为 1/151，重构前后频率比 95% CI 覆盖 1。
  证伪：任一 rank 解码不同，或目标 roster 频率比 CI 排除 1。

- **H3b path-counting 实现被契约证伪**（对照组，预期失败）：该实现按「接受路径数」而非「可见后缀数」计数，
  重构后 `ABABACAC` 的路径数 1→2，概率约翻倍，比值 CI 排除 1。
  证伪（对本假设而言是「没测出差异」）：比值 CI 覆盖 1。

- **H3c 错误实现 2 把私有编码泄漏到可观察输出**：固定 roster `ABACABAB`（3 个合法 handoff 边界），
  在重构前后，"在同一 roster 内均匀挑 handoff 位置" 的 reveal 分布不变（都是 1/3,1/3,1/3），
  但 "在合法路径中均匀挑" 的 reveal 分布从 (1/3,1/3,1/3) 变成 (1/2,1/4,1/4)，
  χ²(2) p < 1e-6。确定化实现的 canonical reveal 恒为最左边界，重构前后完全不变。
  证伪：χ² p ≥ 1e-6，或三个实现的 reveal 都没差异。

### H4（规模：多项式而非指数）

在策略 C 族上（字母表固定 4 个符号，约束固定，只加长 horizon）：

- 计数时间随 n 增长明显慢于可见词空间 `4^n`；从 n=8 到 n=32 的时间增长因子 < 100；
- 记忆化的不同「可达私有状态集合」数 ≤ 1000（远低于 issue 自设的 4,096 上限）；
- 对 n ≤ 10 的实例，确定化计数与独立穷举的计数**逐一相等**（这是方法正确性的第二个独立证据）。

**证伪条件**：每加一个符号时间约 ×2 以上并持续（指数），或可达集合数超过 4,096，或与穷举不符。

诚实边界：确定性自动机的**最坏情况**可达子集数仍是指数的（issue 自己也承认）。H4 只主张
「在这族实例上测得多项式行为」，不主张一般性定理。

## 2. 固定种子与可复现性

- 主种子 `MASTER = 20261128`。
- 每个配置的种子 = `int(sha256(f"{MASTER}|{config_id}").hexdigest()[:16], 16)`，配置 id 见 `RESULTS.md` 表头。
- 抽样器 = `random.Random(seed)`，`randrange(N)`（CPython 的拒绝采样，对大整数无偏）。
- 所有统计量、表格、耗时由 `src/experiments/run_experiments.py` 一次生成，写入 `out/`。
