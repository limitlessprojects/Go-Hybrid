# Wildcard Spike W-4596: Reversible Checked Regions — Synthesize Inverse Code Instead of Rollback Snapshots

> Tracks [`limitlessprojects/Go-Hybrid#4596`](https://github.com/limitlessprojects/Go-Hybrid/issues/4596).

## Summary

This executable spike evaluates opt-in **reversible checked regions** in Hybrid: instead of allocating a full preimage snapshot or write-ahead undo log before a speculative in-memory transformation, a fail-closed static checker admits only provably bijective fixed-width state transformations and mechanically synthesizes an exact executable inverse alongside the forward Go code.

All four falsification criteria specified in `#4596` are implemented and verified in `spikes/w4596-reversible-regions/`:

1. **Pre-registered primitive algebra, overflow semantics, branch-discriminator rule, alias restrictions, and 10 positive / 10 negative corpus** (`reversible_region.py`).
2. **Exact round-trip correctness**: `100,000` seeded random records + `256` boundary & independent reference-interpreter cross-checks **per admitted program** (`1,002,560` total round-trips across all 10 programs), observing **`0` bit mismatches**, and **`10 / 10`** negative programs failing closed with named diagnostics `HYB-REV001`..`HYB-REV010`.
3. **Isolation**: mutable slice aliasing (`HYB-REV004`), channel send (`HYB-REV006`), task spawn/capture (`HYB-REV007`), and indirect foreign Go call (`HYB-REV008`) all fail closed and refuse inverse synthesis.
4. **1 MiB (`1,048,576` bytes) transform-and-abort ROI benchmark**: compares synthesized reversible inversion against copy-before-run snapshot and explicit undo-log baselines using `tracemalloc` peak memory and wall-clock latency, reporting both the memory win (`252 B` vs `1.00 MiB` / `1.58 MiB`) and the honest abort-latency tradeoff.

## 1. Pre-Registered Reversible Algebra & Semantics

All scalar and slice-element operations operate on fixed-width wrapping `uint64` arithmetic ($\mathbb{Z}/2^{64}\mathbb{Z}$), matching Go's defined two's-complement wraparound semantics:

| Forward Primitive | Static Admission Condition | Mechanically Derived Inverse |
| --- | --- | --- |
| `dst += expr` | `dst` mutable, `dst ∉ reads(expr)` | `dst -= expr` |
| `dst -= expr` | `dst` mutable, `dst ∉ reads(expr)` | `dst += expr` |
| `dst ^= expr` | `dst` mutable, `dst ∉ reads(expr)` | `dst ^= expr` |
| `dst = rotl64(dst, k)` | `dst` mutable, `k` constant/immutable | `dst = rotr64(dst, k)` |
| `dst = rotr64(dst, k)` | `dst` mutable, `k` constant/immutable | `dst = rotl64(dst, k)` |
| `dst = -dst` | `dst` mutable | `dst = -dst` |
| `dst = ^dst` | `dst` mutable | `dst = ^dst` |
| `dst *= c` | `c` odd constant ($\gcd(c, 2^{64}) = 1$) | `dst *= c^{-1} \bmod 2^{64}` |
| `swap(a, b)` | `a`, `b` provably disjoint mutable places | `swap(a, b)` |
| `if cond { T } else { E }` | `reads(cond) ∩ writes(T ∪ E) = ∅` (Janus discriminator invariant) | `if cond { inv(T) } else { inv(E) }` |
| `for i := a; i < b; i++ { B }` | `i`, `reads(a,b)` never written in `B` | `for i := b; i > a; { i--; inv(B) }` |
| `call f(...)` | `f` is a checked reversible region | `call f_inv(...)` |

## 2. Example Dual Go Output (`P01_FeistelArxSwap`)

```go
// Code generated by hyb-rev (W-4596) for P01_FeistelArxSwap; DO NOT EDIT.
package reversible

import "math/bits"

type P01_FeistelArxSwapState struct {
	x uint64
	y uint64
	key uint64 // immutable
}

func P01_FeistelArxSwapForward(s *P01_FeistelArxSwapState) {
	s.x = bits.RotateLeft64(s.x, 7)
	s.x ^= s.key
	s.x, s.y = s.y, s.x
}

func P01_FeistelArxSwapInverse(s *P01_FeistelArxSwapState) {
	s.x, s.y = s.y, s.x
	s.x ^= s.key
	s.x = bits.RotateLeft64(s.x, -7)
}
```

## 4. 1 MiB Transform-and-Abort ROI Benchmark (`131,072 x uint64`)

Measured in Python 3 (`array('Q')`, `tracemalloc`) on a 1 MiB (`1,048,576`-byte) in-memory transform-and-abort workload (`mul_odd` + `rotl64` + `xor` + `add`):

| Strategy | Exact Bit Restore | Peak Extra Memory | Forward Latency | Abort / Restore Latency |
| --- | :---: | ---: | ---: | ---: |
| **Synthesized Reversible Inverse** | Yes | **252 B** | **193.48 ms** | 199.99 ms |
| **Copy-Before-Run Snapshot** | Yes | 1,048,880 B (~1.00 MiB) | 207.67 ms | **0.02 ms** |
| **Explicit Undo Log** | Yes | 1,659,496 B (~1.58 MiB) | 238.10 ms | 63.17 ms |

### Cost Honesty & Decision Takeaway
* **Where reversible regions win decisively**: memory-bound and **high-commit-rate** speculative transforms over large owned buffers (multi-MiB states where doubling RAM for a preimage snapshot is prohibitive). Forward latency is actually *lower* than snapshotting (`193.48 ms` vs `207.67 ms`) because no copy is allocated on the happy path, and extra memory overhead drops by **99.98%** (`252 B` vs `1.00 MiB`).
* **Where snapshots win (honest falsifier)**: **high-abort-rate** workloads with ample RAM, where `memcpy` rollback (`0.02 ms`) is orders of magnitude faster than re-running arithmetic inversion (`199.99 ms`), or business logic that requires lossy assignments, dynamic data-dependent branching without preserved discriminators, or external I/O side effects.
* **Scope boundary**: This spike is a standalone Python checker, synthesizer, Go code emitter, and verifier; upstream integration into `hy-check` / `hy-emit` (Rust crates) and `go test` execution of emitted Go packages remain future implementation milestones.
