# Go-Hybrid

[![Go-Hybrid](https://img.shields.io/badge/Go-Hybrid-blue)](https://github.com/limitlessprojects/Go-Hybrid)

## Introduction
Go-Hybrid is an open-source project that aims to replace Tier-0's machinery with a more flexible and efficient alternative. This proposal measures the cost of replacing Tier-0's machinery by porting real Go programs to `.hy` and counting forced concessions.

## Features
1. **Census Table:** A census table will be published with detailed metrics for each ported program.
2. **Decision Rule:** The decision rule will validate or invalidate Tier-0's shape based on the census results.
3. **Porting Process:** Each real Go program will be ported to `.hy` until the checker accepts it, and a detailed diff will be published for each port.

## Getting Started
1. Clone the repository: `git clone https://github.com/limitlessprojects/Go-Hybrid`
2. Install dependencies: `make install`
3. Run the tests: `make test`
